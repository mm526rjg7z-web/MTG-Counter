# MTG Lebenspunkte-Zähler

Lebenspunkte-Zähler für Magic: The Gathering mit Schwerpunkt Commander (EDH), gebaut als Progressive Web App.
Reines HTML, CSS und JavaScript, kein Framework, kein Build-Schritt, keine externen Abhängigkeiten. Läuft komplett offline.

Die App liegt im Ordner [`mtg-counter/`](mtg-counter/). Funktionen, lokales Starten, Veröffentlichen und Installieren
auf dem Handy stehen in der [README der App](mtg-counter/README.md).
